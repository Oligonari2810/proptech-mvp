## 📋 **PENDIENTES PRE-LANZAMIENTO**

### **Configuración Requerida (Manual):**
1. [ ] **Google Analytics Measurement ID**
   - Crear propiedad en analytics.google.com
   - Obtener Measurement ID (G-XXXXXXXXXX)
   - Agregar a Vercel env: `NEXT_PUBLIC_GA_MEASUREMENT_ID`

2. [ ] **Google Search Console**
   - Verificar dominio en search.google.com
   - Obtener código de verificación
   - Agregar a Vercel env: `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
   - Submit sitemap.xml

3. [ ] **APIs Opcionales (para datos geoespaciales reales)**
   - Google Maps API Key (si se quiere green spaces reales)
   - OpenWeather API Key (si se quiere air quality real)
   - Agregar a Render env vars

4. [ ] **Verificación Post-Deploy**
   - Health check ejecutado exitosamente
   - No hay errores en logs
   - Performance aceptable
